01. Linux Kernel Setup & Yama ptrace

On modern Linux distributions (Arch, Ubuntu 22.04+, Fedora, openSUSE), the Yama LSM (Linux Security Module) restricts inter-process debugging to direct child processes by default. PhantomSuite monitors and visualizes this state directly in the cockpit status bar.

Yama Ptrace Scopes

Scope Mode Behavior with PhantomSuite Remediation
0 Classic Full Access Any process with identical UID can read and attach freely. Optimal state. Default for development and CTF machines.
1 Restricted Parent Only Only direct parent processes can attach via ptrace. Launch PhantomSuite via pkexec or modify sysctl.
2 Admin Only Root Only Only processes with CAP_SYS_PTRACE can attach. Run with sudo or grant capability binary bit.
3 Locked Disabled No processes can attach. Requires reboot to reset. Reboot machine with altered boot parameters.
Fast Kernel Configuration

To enable unrestricted memory analysis on your reverse-engineering workstation without rebooting:

# Temporarily set Yama scope to unrestricted
echo 0 | sudo tee /proc/sys/kernel/yama/ptrace_scope

# Persist across reboots in sysctl
echo "kernel.yama.ptrace_scope = 0" | sudo tee /etc/sysctl.d/10-ptrace.conf
sudo sysctl --system

Scanning Modes

  • Exact Value: Match memory cells equal to target value.
  • Increased / Decreased Value: Relative search against previous scan snapshot. Ideal when values lack visible on-screen numbers (health bars, stamina meters).
  • Changed / Unchanged Value: Detect volatile memory addresses vs static configuration.
  • Unknown Initial Value: Captures entire writable heap/stack space on First Scan, allowing differential pruning on subsequent scans.
Fast-Scan Alignment Heuristic

Always keep Fast Scan (Alignment: 4) checked when hunting 32-bit integers or floats! On x86_64, compilers virtually always align integer variables to 4-byte or 8-byte boundaries. Scanning only aligned addresses cuts scan execution time by 75% and eliminates cache misalignments.

06. ASLR-Resilient .phantom Tables

Linux binaries use PIE (Position Independent Executables) and ASLR (Address Space Layout Randomization). Hardcoded absolute memory addresses break every time the application is relaunched.

The .phantom Table Architecture

When you save a cheat table via Ctrl+S, PhantomSuite converts raw memory addresses into Module Relative Offsets or Symbolic Pointer Paths: 

{
  "version": "2.0",
  "target_name": "GameClient.x86_64",
  "entries": [
    {
      "description": "Player Health",
      "address": "GameClient.x86_64 + 0x48A020",
      "type": "int32",
      "freeze": true,
      "freeze_value": 9999
    },
    {
      "description": "Camera FOV Pointer",
      "pointer_path": ["UnityPlayer.so + 0x18F4200", 0x38, 0x10, 0x118],
      "type": "float",
      "freeze": false
    }
  ]
}

Upon reloading a table, PhantomSuite dynamically queries /proc/[pid]/maps, re-resolves the module base addresses, recalculates the effective virtual addresses, and re-attaches value freezers.

07. Differential Snapshot Forensics

  1. Capture Snapshot A: Captures memory across all readable/writable pages (excluding read-only text segments).
  2. Trigger Event in Target: Equip an item, shoot a weapon, or trigger a game menu transition.
  3. Capture Snapshot B: Compares memory deltas byte-by-byte.
  4. Filter Mutation Clustered Regions: PhantomSuite highlights contiguous memory pages with modifications, allowing you to isolate state variables in seconds.

08. Virtual Address Space Treemap

The Treemap Tab generates a real-time, proportional visual map of the entire 48-bit virtual address space:

  • ■ Executable Code (r-x): Main binary text segment, dynamic shared libraries (libc.so, libunity.so).
  • ■ Heap (rw-): Dynamic memory allocated via brk or mmap.
  • ■ Stack (rw-): Thread execution stacks and local variables.
  • ■ Anonymous mmap (rw-): Large buffers, game assets, and mono heap pages.

Clicking any partition in the treemap automatically navigates the Hex Viewer to the start of that page.

19. Sandboxed Micro-Execution & Sub-Function Emulation

The Micro-Emulator Tab provides an isolated, safe x86_64 CPU state emulation cockpit for stepping through complex sub-routines (e.g. string decryption loops, license checks, packing routines) without executing them in the target process.

Operational Capabilities

  • Copy-on-Write Shadow Paging: Reads memory pages lazily from the target process on demand. Any memory writes made during emulation exist only inside PhantomSuite's shadow memory—never altering the live process.
  • Step-by-Step Tracing (F7 / F8 / F9): Step instructions one-by-one or run until ret. The execution trace table logs mnemonics, operands, register deltas, and memory reads/writes.
  • Live Register Grid with Delta Highlighting: 64-bit general registers (RAX..R15, RIP) are editable in real-time. Any register that changes value during an execution step glows in neon orange.
  • Shadow Stack Inspection: Monitors 16 QWORDs relative to RSP.
  • State Snapshots & Undo Stack: Click "💾 Snapshot" before testing branch paths. If execution faults or enters an infinite loop, click "⏪ Rollback" to restore CPU registers and shadow pages instantly!

20. Shannon Entropy & Cryptographic Scanner

The Entropy & Crypto Tab detects encrypted memory blocks and identifies standard cryptographic lookup tables and constants:

Shannon Entropy Formula

H = - Σ (p_i * log2(p_i))   where p_i is the frequency of byte i (0..255)
Theoretical Range: 0.0 bits/byte (zero-filled) to 8.0 bits/byte (pure randomness / encrypted)

Classification Thresholds

Entropy Range Classification Color Coding Typical Contents
H ≥ 7.5 Encrypted / Packed Neon Red / Pink AES ciphertext, compressed zlib/gzip assets, packed shellcode.
5.0 ≤ H < 7.5 Code / Structured Cyan Compiled x86_64 machine instructions, structured C++ objects.
H < 5.0 Sparse / Text Green ASCII/UTF-8 strings, zero-initialized tables, sparse matrices.

Cryptographic Signature Database

Scans memory maps for:

  • AES: Rijndael Forward S-Box, Inverse S-Box, Key Schedule Rcon Table.
  • SHA-2: SHA-256 Initial Constants (H0-H7), Round Constants (K0-K7).
  • ChaCha20: Sigma constant "expand 32-byte k".
  • MD5 & CRC32: Standard hash vectors and lookup polynomials.
  • Curve25519: Base point and prime field constants.
